Ingest → Ground truth: structure and flow

Draft · 2026-11-23 · Scope: ingest and distill only; resume writing is out of scope

Structure

raw/                                 # commit only the example
├── repository-mapping.example.yml   # schema with fake values
└── <company>/                       # real names and the Jira token
    ├── mapping.yml                  # config, edited by the user
    ├── TODO.md                      # todos for this company's data
    ├── jira/<yyyy>.json             # Jira data
    └── <id>/
        └── <repo-name>/             # repository data
evidence/                            # commit all: anonymised data
└── <company>/<yyyy-project-slug>.md  # ground truth
scripts/                             # commit all: written by the LLM
└── …                                # process raw → evidence, query raw Jira data
FolderCommittedWritten by
raw/Only repository-mapping.example.ymlUser (mapping.yml), scripts (everything else)
evidence/AllLLM, reviewed by the user
scripts/AllLLM, when a step needs a reusable helper (Python, run with uv)

company: themather

# Commit identity, used to find my commits
me:
  names: [altr, chuan, phattharanat]
  emails: [chuan.khuna@gmail.com, phattharanat@gmail.com]

# Credentials for the script to download tickets (optional)
jira:
  site: <site>.atlassian.net
  email: <login email>
  api_token: <token>

projects:
  - id: <project-slug>       # raw/<company>/<id>/ and evidence/<company>/<yyyy>-<id>.md
    internal_name: <real name> # stays in raw/; never appears in evidence/
    title: <anonymised name>
    sources:
      - <git repo url>

Flow

1 · Ingest

  1. Update config. The user edits raw/<company>/mapping.yml.
  2. Load repository data. The script clones each source into raw/<company>/<id>/<repo-name>/, or fetches it if it is already there.
  3. Load Jira data. If jira: is set, the script downloads all tickets assigned to me into raw/<company>/jira/<yyyy>.json.

2 · Distill

  1. Use data in raw/<company>. For one project: my commits (matched by me), the paths I own, dependency files and docs in its repos, and its related Jira tickets.
  2. Distill to ground truth. Write evidence/<company>/<yyyy-project-slug>.md, where yyyy is the year of my first commit in the project. Every What I Did bullet cites its evidence. The user reviews the file once.

Ground truth file

---
id: <project-slug>

Scripts

The LLM writes scripts into scripts/ as it needs them, rather than to a fixed list up front. Scripts read paths and credentials from raw/<company>/mapping.yml, never from hard-coded values, so they hold no client names and are safe to commit. Expected ones:

ScriptStepDoes
ingest <company>1Load repository data and Jira data from the config
jira query <company> …2Filter raw Jira tickets (by text, project, epic, date) for one project
authorship <company> <id>2Show my commits and the paths I own in a project's repos
